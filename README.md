# SNA Virtual Laboratory & STEAM Hub

**Sealed Nectar Academy** — interactive STEAM learning hub (single-page web app).

## Live
After deploy: your Vercel URL (e.g. `https://sna-steam-hub.vercel.app`)

## Contents

### Chemistry Lab
Galvanic cells, electrolysis, redox, periodic trends, matter, elements, compounds, mole concept, organic chemistry, and more — with animations and quizzes.

### Language & Literature
- Language skills (parts of speech, oral English / IPA, writing, etc.)
- **WAEC literature (2026–2030 style modules)** with **Story Animation**:
  - *To Kill a Mockingbird* (Harper Lee)
  - *Once Upon an Elephant* (Bosede Ademilua-Afolayan)
  - *Redemption Road* (Elma Shaw)
  - *An Inspector Calls* (J. B. Priestley)
  - *The Marriage of Anansewa* (Efua T. Sutherland)
  - *Antony and Cleopatra* (William Shakespeare)
  - *Path of Lucas* (Susanne Bellefeuille)
  - *A Man for All Seasons* (Robert Bolt)

Each literature module includes: Story Animation (playable scenes), intro, plot, characters, themes, and a 20-question practice quiz with listen buttons (Web Speech API).

### Other subject hubs
Physics, Biology, Basic Technology, Geography, Agricultural Science — structure ready for expansion.

## Run locally
Open `index.html` in any modern browser (Chrome/Edge recommended for speech).

## Deploy (Vercel)
1. Push this repo to GitHub.
2. In Vercel: **Add New Project** → import this repository.
3. Framework: Other · Output: leave default · Deploy.
4. Site serves `index.html` at the root.
